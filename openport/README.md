# Openport

Reach your Home Assistant installation from anywhere through an
[openport.io](https://openport.io) https tunnel.

No port forwarding, no static IP, no dynamic DNS: the add-on opens an outbound
tunnel from your Home Assistant to the openport servers, and your dashboard
becomes reachable on a stable `https://<xxxxx>.u.openport.io` address.
WebSockets are fully supported, so the frontend and the companion mobile apps
work out of the box.

See [DOCS.md](DOCS.md) for setup instructions.
